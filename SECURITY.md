# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | ✅        |

## Reporting a Vulnerability

The Delusional Handbook is a simple Express server serving static files:

- No database
- No user accounts
- No authentication
- Data lives in browser `localStorage` only
- `/api/health` is a read-only status endpoint

If you find a security issue, please open a GitHub issue.

## Disclosure

We will acknowledge receipt within 72 hours.
