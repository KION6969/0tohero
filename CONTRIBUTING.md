# Contributing to The Delusional Handbook (0tohero)

Thanks for your interest! The Delusional Handbook is a sarcastic personal-goals dashboard with Node.js, Express, HTML, CSS and vanilla JavaScript.

## How to contribute

1. **Fork the repo** and create a branch from `main`.
2. **Make your change** — calculator, UI, excuse, or docs.
3. **Run the server** — `npm start` and verify `http://localhost:3000/api/health` returns 200.
4. **Test the health endpoint** — `curl http://localhost:3000/api/health`.
5. **Commit with a clear message** — e.g. `feat: add SIP calculator`.
6. **Open a pull request** — describe what changed and why.

## Guidelines

- Keep the jokes — sarcasm is the point
- No build step — vanilla HTML/CSS/JS
- All calculations are illustrative, not financial advice
